# 손질 과정 이미지 제작 기록

- 제작 도구: 기본 내장 image_gen (AI 생성 및 보관법 2단계 장면 수정)
- 이미지 위치: 이 폴더의 재료 ID별 `.webp` 29개
- 용도: 양파를 제외한 29개 안내 글의 단계별 과정 장면 91개
- 기존 양파의 과정 사진 3장은 유지했습니다.
- 각 파일은 3개 또는 4개 장면이 세로로 연결된 이미지입니다. 웹페이지에서는 각 장면을 해당 단계에 맞춰 나눠 표시합니다.
- 3단계 글은 4:3, 기존 4단계 글은 16:9로 표시해 원본 비율을 보존합니다.
- 웹용 파일은 768×1728 WebP, 품질 80입니다.
- 생성 프롬프트 전체: [generation-prompts.json](generation-prompts.json)
- 보관법 이미지의 2단계는 흐르는 물로 씻는 장면에서 깨끗한 타월로 물기를 닦는 장면으로 수정했습니다.
- 사진은 실제 촬영 기록이 아닌 AI 예시입니다. 세척·칼 사용 등 실제 작업에서는 본문 안내를 따르도록 표시했습니다.
