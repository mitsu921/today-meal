# Ingredient preparation example images

These 20 images were generated with the built-in image generation tool on 2026-10-25 for TodayMeal. Each depicts one named ingredient, whole and partly prepared, on a light kitchen surface. They are illustrative AI images, not documentary photographs or an authoritative step-by-step demonstration. The site labels them accordingly; written preparation instructions take precedence.

The source PNGs are preserved outside the repository. Published assets are resized to 768 x 576 and encoded as WebP (quality 80). Filenames match the guide IDs in scripts/more-ingredient-guides.mjs. The guide builder connects each image to its list card, article and social preview. Saved cards use the same file.
