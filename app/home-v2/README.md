# TodayMeal Home v2

`reference.png` 시안을 기준으로 만든 실제 수정 가능한 HTML/CSS/JS 소스입니다.

```
index.html    구조 (아이콘은 전부 인라인 SVG)
styles.css    반응형 UI
app.js        추천 메뉴 캐러셀 · 버튼 · 토스트
assets/       일러스트 4종 (투명 배경 PNG)
reference.png 기준 시안
```

## 화면을 이미지로 쓰지 않았습니다

텍스트 · 카드 · 버튼 · 칩 · 하단 내비게이션은 모두 실제 DOM입니다.
아이콘도 이미지가 아니라 인라인 SVG입니다.

- 로고 셰프햇, 알림 종, 햄버거
- 필터 칩 4종 (가족 / 시계 / 냉장고 / 동전)
- 바로가기 4종 (냉장고 / 장바구니 / 책 / 카메라)
- 추천 카드 메타 아이콘 (시계 / 잎 / 하트), 반짝임
- 히어로 장식 (하트 / 잎 / 반짝임 / 잔가지)
- 하단 내비 5종 (홈 / 셰프햇 / 냉장고 / P / 사람)

이미지 자산은 **여자, 음식 그릇, 돼지저금통, 룰렛** 4개뿐입니다.

## 좌표 기준

`reference.png` 는 853 × 1844 이며, 이는 **430 × 932 CSS px 의 정확히 2배**입니다.
CSS 값은 이 배율(÷2)로 시안에서 역산한 실측값입니다.

| 영역 | top | 높이 |
|---|---|---|
| 상단바 | 0 | 66 |
| 필터 칩 | 206 | 44 |
| 추천 카드 | 258 | 211 |
| 바로가기 카드 | 503 | 108 |
| 절약 리포트 | 621 | 115 |
| 룰렛 배너 | 749 | 88 |
| 하단 내비 | 854 | 78 |

좌우 여백은 18px, 카드 폭은 394px입니다.

## 추천 메뉴 캐러셀

`.recommend-card` 를 슬라이드 3장짜리 트랙으로 확장했습니다.
카드 마크업 자체는 기존 구조(`meal-copy` / `pill` / `meal-meta` / `meal-actions`)를 그대로 유지했습니다.

```
.recommend
└ .carousel            overflow-x:auto + scroll-snap-type:x mandatory
  └ .carousel-track    display:flex
    └ .carousel-slide  flex:0 0 100%   ×3
└ .carousel-dots
```

조작 방법 네 가지를 모두 지원합니다.

- **터치 스와이프** — 브라우저 네이티브 스크롤 스냅
- **마우스 드래그** — 데스크톱에서 포인터 이벤트로 처리
- **방향키** — 캐러셀에 포커스한 뒤 ← →
- **도트 클릭**, **"다른 메뉴 볼래요" 버튼**

슬라이드 위치가 바뀌면 도트가 자동으로 따라오고, `aria-selected` 도 함께 갱신됩니다.

### 구현할 때 주의한 것

세 가지 함정이 있어서 코드에 그대로 남겨뒀습니다.

1. `.carousel` 을 `display:flex` 로 두면 슬라이드의 `flex:0 0 100%` 가 순환 참조되어 카드가 화면 밖으로 삐져나갑니다. `display:block` + 트랙만 flex 로 해야 합니다.
2. 드래그를 끝낼 때 `scroll-snap` 을 먼저 되살리면 브라우저가 목표 위치를 무시하고 원래 자리로 되돌립니다. 위치를 옮긴 뒤 `requestAnimationFrame` 에서 스냅을 복구합니다.
3. `pointerdown` 즉시 드래그 모드로 바꾸면 자식의 `pointer-events` 가 꺼져 **단순 클릭의 타깃이 버튼에서 캐러셀로 바뀝니다.** 4px 이상 움직였을 때만 드래그로 전환합니다.

### 메뉴 데이터 교체

슬라이드는 `index.html` 에 정적으로 3장 들어 있습니다(JS 없이도 렌더됩니다).
메뉴를 바꾸려면 각 `.carousel-slide` 안의 제목 · 메타 · `img[src]` 만 고치면 되고,
장수를 늘리거나 줄이면 `#mealDots` 의 `.dot` 개수만 맞춰 주면 됩니다.

> 현재 2 · 3번 슬라이드는 사용할 수 있는 음식 사진이 `meal_bowl.png` 하나뿐이라
> 같은 이미지를 쓰고 있습니다. 사진이 준비되면 `img[src]` 만 교체하세요.
