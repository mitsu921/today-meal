TodayMeal 랜덤 초안 + 사진 검토 작업실

1. GitHub 업로드
- factory.html: 저장소 최상위 기존 파일 교체
- factory-studio.js: 저장소 최상위 새 파일 추가
- api/factory-image.js: api 폴더에 새 파일 추가
기존 app/index.html, api/menu.js, 사진/CSS 파일은 교체하거나 삭제하지 않습니다.

2. 즉시 가능한 기능
음식 이름 없이 AI 초안 만들기를 누르면 대상에 맞춰 메뉴부터 생성합니다.
음식 이름을 입력하면 해당 요리의 초안을 만듭니다.
다른 랜덤 메뉴로 초안 만들기는 입력한 음식 이름과 무관하게 새 메뉴를 요청합니다.
최근 40개 생성 메뉴를 이 브라우저에 저장해 프롬프트에서 제외하며 같은 음식 이름이 나오면 다시 요청하도록 안내합니다.
서로 다른 표현으로 쓴 같은 음식까지 완전히 구별하지는 않습니다.
등록은 반드시 기존 등록하기 버튼을 직접 눌러야 합니다.

3. 자동 사진 생성 설정 (별도 API 비용)
Vercel 프로젝트의 Settings → Environment Variables에서 다음을 설정하고 다시 배포하세요.
- OPENAI_API_KEY: 이미지 생성 권한과 결제가 활성화된 OpenAI API 키
- FACTORY_ADMIN_EMAILS: Supabase에서 확인된 운영자 계정 이메일. 여러 명이면 쉼표로 구분.
선택: FACTORY_IMAGE_MODEL (기본 gpt-image-2)
키는 GitHub/HTML/이 대화에 적지 말고 Vercel 환경변수에만 저장하세요.
ChatGPT 구독과 API 사용료는 별개입니다. 이미지 생성/재생성마다 API 비용이 발생할 수 있습니다.
Vercel 실행 환경이 최대 120초 함수 설정을 지원해야 합니다. 환경의 시간 제한이 더 짧으면 생성 요청이 중단될 수 있습니다.
환경변수가 없으면 명확한 안내를 표시하고 레시피 초안은 유지합니다. 직접 사진 업로드·미리보기는 API 키 없이 가능합니다.

4. 사용 흐름
대상 선택 → 음식명 입력 또는 비워두기 → AI 초안 만들기
'초안 완성 후 AI 참고 이미지도 생성'이 켜져 있으면 초안 완성 후 이미지 요청.
사진 미리보기 → 수정 요청 작성 후 이미지 생성/다시 생성 또는 직접 찍은 사진으로 교체 → 사진 확인 체크 → 등록하기.
수정 요청은 현재 이미지를 부분 편집하는 것이 아니라 현재 레시피와 요청으로 새 이미지를 만드는 방식입니다.
AI 이미지는 실제 촬영 사진이 아닙니다. 공개 글 본문에 AI 참고 이미지라는 표시가 자동으로 남습니다.
레시피 내용이나 사진을 바꾸면 확인 체크가 해제됩니다.
이미지를 생성한 뒤 확인하지 않으면 사진이 포함된 등록을 막습니다.
이미지 생성/수정 기능은 로그인된 운영자 허용 이메일만 사용할 수 있습니다.

5. 확인한 범위
JS 구문, 랜덤/직접 입력/최근 중복 처리, 등록 전 사진 확인 조건, AI 출처 표시, 서버 설정 누락 안내, 비운영자 차단 및 정상 요청 형식을 모의 응답으로 검증했습니다.
실제 유료 이미지 생성 API, 사진 품질, 실제 계정 게시와 모바일 미리보기는 아직 미검증입니다.
이미지가 실사처럼 보이는 정도와 재료 일치 여부는 결과를 보고 검토해야 합니다.
